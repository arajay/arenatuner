# Copilot Agent Skills

This folder contains example skills for the arenatuner Copilot agent.

- `basic-skill.md` — a simple skill that demonstrates how to provide clear guidance and tool-like responses.
- `react-typescript-skill.md` — React and TypeScript guidance for the arenatuner frontend.
- `mui-skill.md` — Material UI best practices for layout, theming, and controls.
- `mui-theme-mastery-skill.md` — advanced MUI theme mastery for palette customization, dark mode, and design system consistency.
- `vite-skill.md` — Vite tooling and local development workflow advice.
- `unit-testing-skill.md` — unit testing guidance for Vitest, `happy-dom`, and React component tests.
- `skill-creator.md` — a helper skill that can propose and create new skills when new functionality or areas of guidance are needed.
