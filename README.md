# Arena Tuner

A small React + TypeScript + MUI web UI for tweaking Magic: The Gathering Arena Historic best-of-one decks.

## Stack
- React
- TypeScript
- Vite
- Material UI

## Quick start
1. Run `pnpm install`
2. Run `pnpm run dev`
3. Open the local app in the browser

## Goals
- deck list editing
- card suggestions
- best-of-one tuning workflows
